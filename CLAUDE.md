Always aim for simple, readable, idiomatic code. Avoid unnecessary complexity
and strive for clarity in your code. Use meaningful variable and function names,
and break down complex problems into smaller, manageable pieces. Remember that
code is read more often than it is written, so prioritize readability and
maintainability in your coding style. WET cod is better than DRY code. Don't
worry about optimization, we can be generous in our use of resources, such as
the k8s api calls.
